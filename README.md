# The Curiosity Cabinet

The Curiosity Cabinet is an interactive digital museum designed for explorers, collectors, and lifelong learners.

Inspired by the historical cabinets of curiosities, the application allows visitors to discover fossils, artifacts, books, instruments, mythology, historical objects, and unusual discoveries through interconnected stories, timelines, and related concepts.

Built with React and modern web development practices, the project emphasizes responsive design, thoughtful information architecture, accessibility, and engaging user experiences. Rather than presenting information as a static database, The Curiosity Cabinet encourages curiosity-driven exploration where every object connects to a larger story.

Features
Browse curated collections
Search and filter artifacts
Interactive artifact pages
Historical timelines
Related concepts and discoveries
AI-assisted exploration
Responsive and mobile-friendly design
Museum-inspired user experience
Purpose
The project explores how thoughtful UX, storytelling, and information architecture can transform collections of information into engaging digital experiences.
