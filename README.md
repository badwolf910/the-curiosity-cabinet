# The Curiosity Cabinet

The Curiosity Cabinet is a digital museum for the curious.

Part collection, part encyclopedia, and part storytelling experience, it allows visitors to explore fossils, artifacts, mythology, books, scientific discoveries, and other unusual objects through interconnected histories and ideas.

The project grew from a lifelong fascination with collecting, investigating mysteries, and discovering the unexpected. Every object has a story, and every story connects to something larger.

Built with React and modern web development practices, the goal is to make exploration feel as rewarding as wandering through a real museum.
